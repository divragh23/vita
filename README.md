# Vita

Vita is a web-based health assistant for everyday wellness questions — symptoms,
sleep, nutrition, hydration, stress, fitness, and common illnesses. It offers
general, evidence-based information and consistently points toward professional
care for anything that needs it. It is not a medical service and does not
diagnose or prescribe.

## Overview

Conversations stream in real time. Responses are formatted in Markdown and
include links to credible sources such as the CDC, Mayo Clinic, MedlinePlus,
and the WHO. The assistant is built to recognise urgent situations and direct
people to emergency services rather than continue with general advice.

Alongside chat, the app includes a browsable set of common health topics, the
ability to save useful responses as tips, and light and dark themes.

## Stack

The front end is a React single-page app built with Vite and styled with
Tailwind CSS. The back end is a Node.js and Express service that streams model
output to the client over server-sent events. Responses are generated by Llama
3.3 70B served through Groq.

## Structure

```
client/   React front end
server/   Express API and streaming endpoint
```

## Configuration

The server reads its settings from environment variables: a Groq API key for
the model, an allowed origin for production CORS, an optional port and
per-minute rate limit, and Gmail SMTP credentials used to deliver feedback. A
template is provided in `server/.env.example`.

## Disclaimer

Vita provides general health information for educational purposes only. It is
not a substitute for professional medical advice, diagnosis, or treatment, and
should not be relied on for medical decisions. In an emergency, call 911 or
local emergency services.
